# 建造层「史蒂夫的家园」设计规范

> 状态：已批准 · 2026-07-31
> 规则与数值的**权威来源**：`docs/edu-pm-reviews/2026-07-31-build-layer-review.md`（含 M8/M9 新纪律、
> 观察清单增补、调参判据）。本文只列工程契约；冲突以评审为准。

## 0. 已定决策

玩具不是游戏（无对错/任务/评分/样板蓝图）；16×9=144 格固定地皮，**永不扩建**；
1 煤 = 1 方块**永久统一价**（铁则，禁差异定价；方块永远只收煤）；拆除（措辞「收回」）
全额退、即时、无确认；v1 托盘 11 种（8 基础 + 白/红/蓝羊毛）；家园天色恒定夜；
**M8** 角色无需求无召回；**M9** 无任何完成度表征（禁 N/144、进度条、空地高亮）；
家园不上地图屏；信息架构 = 进屏即家园，衣柜/工作台为抽屉（图标按钮 + 场景同义入口双通道）；
点星仍只在工作台内；收回 = 托盘小锤子模式切换。

## 1. 数据与账目

```ts
// RewardsSlice 增：
homeGrid: (string | null)[];   // 长度 144（16×9 行优先），blockId 或 null
```

`spent().coal` 增加一项：`#{homeGrid 非空格} × 1`。**收回无退款操作**——余额本就是
`income − spent` 的派生值，格子清空即回落（架构自愈性的又一次白拿）。
迁移：旧档无字段 → 全 null（merge-over-defaults）。

## 2. 方块目录 `rewardsCatalog.ts`

```ts
BLOCKS: { id: `blk-*`; name: string }[]  // 11 种：grass/dirt/wood/stone/glass/fence/flower/torch/wool-white/wool-red/wool-blue
BLOCK_PRICE_COAL = 1                     // 常量而非 per-block 字段——铁则在类型层面固化
```

核心函数（纯，TDD）：`placeBlock(p, i, id)`（煤 ≥1 且格空）、`removeBlock(p, i)`、
幂等/越界拒绝、`balance ≥ 0` 恒成立。

## 3. UI

- **SteveScreen 重构**：主视图 = 家园场景（网格 + 地面 + 星空层 + 史蒂夫/宠物走动）。
  右上两图标钮：衣柜（现装备 tab 内容）/ 工作台（现 bench 内容），以抽屉面板叠加展开；
  场景内点史蒂夫 = 开衣柜（他打个招呼）、点工作台方块（场景固定位）= 开工作台。
- **托盘**：底部「方块」按钮唤出；11 方块 + 小锤子（收回模式，激活时格子加描边提示）；
  托盘上显示煤余额（M9 允许的唯一数字）。
- **方块渲染纯 CSS**（预览已验证观感）：草/泥土/木板/石头/玻璃/栅栏/花/火把/羊毛三色，
  零素材成本。
- **宠物走动**：已购宠物类配件（小鸡/小狗/鹦鹉/小猫）在家园地面随机走动
  （CSS transition + 定时器）；非宠物配件仍按锚点跟随史蒂夫。全部无需求（M8）。
- **星空**：`skyStars` 单一计数，地图夜空与家园上空**双处渲染**（抽 SkyLayer 组件共用），
  不得分裂成第二种星。家园天空纯展示，无点星操作。
- **结算屏零改动**（不加「去搭点什么」——评审条款化）。

## 4. 语音与文案（评审 C 表照抄；新中文 → 重跑字体子集）

首进家园欢迎（替换现 steveWelcome）；首 3 次收回「煤收回来了」（会话内计数即可）；
煤说明卡追加「家园里用了 N 块煤，收回就能拿回来」；星说明卡追加
「方块可以收回，星星点亮了就一直亮着」。措辞：放置=「搭」、拆除=「收回」。

## 5. 家长面

重置二次确认文案更新：「史蒂夫的家、装备和你点亮的星星都会一起消失」。
观察清单按评审增补（第 3 条打补丁 + 新 7–10 条 + 健康信号增补）。
开关关闭 = 隐藏入口，**已搭建筑保留**（扒家等于没收）。
