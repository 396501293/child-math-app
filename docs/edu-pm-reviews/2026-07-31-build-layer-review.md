## 结论摘要

1. **建造层补上的是前两轮一直没补齐的「玩」的容器，而且顺带修正了我自己上一轮的一个薄弱设计。** 次轮把星空定为「终局层主角」，让它同时承担「玩」和「耗」双职——诚实地说，45 星图样之后的自由点星作为玩法是很薄的。家园接走「玩」的职能后，三层第一次各司其职：**装备/配件 = 里程碑层（有顶），家园 = 表达层（净零消耗、无限重排），星空 = 唯一永久沉没端 + 常驻记录层（无限）**。星空不是被冷落了，是被卸掉了不擅长的活。
2. **「机会成本仍在」的判断：验证成立，但只在短期成立——而这恰恰是对的。** 建造中的煤是「冻结」不是「消灭」，短期内挤占点星与煤→铁兑换（流动性成本真实存在）；长期煤可再生、累计无上限，机会成本自然消解。玩具不应该永远稀缺。144 格即天然上限，**不另设上限，且 v1 不做扩建、也不建议未来做**（理由见问 3）。
3. **星空：不调价（10 煤/颗不动），调定位；接受上线初期的点星放缓，给 6 周判据**（连续 6 周 skyStars 零增量且煤余额 > 50 才动作，动作是改说明卡与语音，不是降价）。
4. **玩具边界确认无保留，但要立两条新纪律防「回潜的游戏化」**：M8（场景角色无需求、无召回——史蒂夫和宠物不饿、不困、不想你）；M9（家园无任何完成度表征——永不显示 N/144、进度条、空地高亮）。家园最大的风险不在经济，在于后续迭代手痒给它加目标。
5. **1 煤 = 1 方块确认，并升级为永久统一价铁则（禁止任何方块差异定价）**；托盘推荐 8 → 11（补白/红/蓝羊毛三色，像素表达缺原色）；「一章 = +2 种主题方块（免费入托盘）」写进内容更新对应规则。
6. **信息架构：进屏即家园**，装备（衣柜）与工作台做抽屉，场景内的工作台方块做同义入口——导航从「标签抽象」变成「场景具象」，这是 CPA 逻辑在导航层的应用，对 4–8 岁明确更顺。
7. **结算屏不加「去搭点什么」：同意，且写成硬条款。** 结算屏的「+2 煤」一行已是全部桥梁，孩子自己会完成推理；替他说出来就是 M2 禁止的未来式许诺加广告。

## 继承条款在建造层的读法（不改条款，只给映射）

| 条款 | 建造层读法 |
|---|---|
| M1 矿石不进答题屏 | 不变；家园及方块元素同样零出现于答题屏与结算屏（结算只保留既有「+N 煤」行） |
| M2 语言纪律 | 放置说「搭」、拆除说「**收回**」（不说「拆掉/毁掉」——收回强化退款语义）；禁「你的家还差……」类措辞 |
| M3 近端化 | 家园本身就是 16×9 的阵列（P 层表征天然自带）；煤说明卡加一句「家园里用了 N 块煤，收回就能拿回来」 |
| M4 自主性 | 建造层是全系统自主性密度最高的一层，天然满足；不加引导性目标去污染它 |
| M5 事后惊喜 | 新章方块**免费直接入托盘**，孩子在家园里自己发现；地图不预告 |
| M6 家长开关 | 「史蒂夫养成」开关覆盖家园；关闭 = 隐藏入口，**已搭建筑保留不清除**（扒家等于没收，同扒衣服禁令） |
| M7 角色不做角标 | 扩展：家园不出现在地图屏（星空维持现状）；地图上的史蒂夫不因「家里有新方块」有任何暗示 |
| 矿石不耦合内容 | 方块不解锁关卡、不改难度；反向（新章送方块）允许，同装备阶先例 |
| 禁统计展示玩耍行为 | 「不统计不展示换装次数」扩展为**不统计不展示任何方块操作次数**（家长小结里也不出现） |

## 逐问回答

### 问 1：全额退的经济后果——机会成本还成立吗？要不要设上限？

**你方判断成立，补两个限定后采纳。**

余额架构下的账目：`spent` 新增一项 `已放置方块数 × 1`，拆除即回落——余额仍是 `Progress` + 家园网格的纯函数，可随时重算自愈，首轮 §3.1 架构原样兼容。冻结在墙里的煤确实不能同时点星或兑铁，**在每一个花费决策的当下，机会成本是真实的**（「10 块煤：点 1 颗星，还是搭 10 个方块？」——这本身是一次健康的数量比较，是数学时刻，不是漏洞）。

两个限定：

1. **机会成本随时间单调衰减。** 煤收入可再生（常规画像主线期 28/周、毕业后 12/周，弱画像 10/周），满铺 144 格相当于常规画像 5–12 周、弱画像 14+ 周的全部煤收入——没人会一夜铺满，稳态（约 3 个月后）煤足以覆盖家园 + 星空 + 配件。**稀缺感消失是设计内结局**：玩具不应该靠稀缺维持，装备阶梯的稀缺由铁/金/钻/绿承担，而建造层被「只收煤」规则结构性隔离在外——这是次轮「星空只收煤」同一条隔离规则的第二次应用。
2. **唯一真实的经济摩擦点是弱画像的煤→铁救济通道**（首轮为铁阶设计的兜底阀）。煤进了墙就暂时不能换铁，弱孩子铁阶（本就是全场最慢点）可能再慢。因为可全额收回，这不是死锁，是认知问题——孩子未必想到「收回墙上的煤去换铁」。对策进观察清单（增补第 9 条）与调参表 G 行扩展，不改数值。

**上限：不另设，144 格即上限，且此上限因「不做扩建」（问 3）而永久成立。** 额外规则一条：**方块永远只收煤**——未来任何新方块种类都不得以铁/金/钻/绿定价，否则隔离墙失效。

### 问 2：可逆消耗 vs 永久消耗并存——星空会被彻底冷落吗？

**短期会放缓，长期不会被替代——因为建造层根本不是沉没端。** 关键账目事实：家园净消耗为零，**煤的永久去向全系统只剩星空一个**（配件煤额 76 是有限目录）。家园吸走的是注意力，不是煤；星空的结构地位反而从「之一」变成「唯一」——**更重要了**。

预期与对策：

- **接受「建造潮」**：上线后 2–4 周孩子把余煤优先变成方块，点星停滞，正常。45 星 ≈ 450 煤的图样进度本来就是 30+ 周的慢燃线，拉长到 40 周无妨。
- **不调价。** 降到 5 煤/颗去「竞争」违反「价格确定、可解释、不变动」原则（继承禁随机的同一精神），且等于承认星空要靠性价比取胜——它的胜负手从来不是性价比，是**永久性与在场性**：星星点了永远亮，且同时出现在地图夜空和家园上空（单一 `skyStars` 计数、两处渲染，**不得**分裂成「家园星」第二货币）。
- **定位重划（写进规范）**：家园 = 「玩的」（方块来了又去），星空 = 「记下来的」（星星永远亮着）。星星说明卡加一句区分：「方块可以收回，星星点亮了就一直亮着」。星座图样的轮廓与集齐连线庆祝维持原样，那是星空独有的高光。
- **6 周判据（进调参表）**：家园上线后连续 6 周 `skyStars` 零增量、且煤余额 > 50 → 说明「永久性」没有传达到 → 动作是重写说明卡文案 + 让下一个未完成图样的轮廓在家园上空可见（提示「这里可以亮起来」的静态信息，非推送），**仍然不动价格**。

### 问 3：玩具边界——无对错确认？地皮固定还是可扩建？

**无对错、无任务、无评判：确认，无保留。** 论证只需三条：① 搭建类开放游戏是 4–8 岁的发展原生形态（积木游戏与空间能力的关联是幼教研究里最扎实的结论带之一），它不需要目标就自带可玩性；② 游戏化元分析里唯一稳定见效的维度是自主感，家园是全系统自主性密度最高的一层，加任何评判都是往里掺杂控制感；③ 一旦出现「样板/任务/评分」，玩具即刻退化回游戏，重新引入我们刚刚诊断出的「买完即终」问题的变体（「搭完任务即终」）。**推论：v1 不提供样板蓝图、不提供预置建筑**——样板会变成隐性标准（「我搭得不像图」）。空白画布焦虑由首进语音化解（见文案表），且场景并不空：史蒂夫在走、宠物在走、星在头顶。

**地皮：固定 144 格，不做扩建——包括未来也不建议做，这是本文与提问预设分歧最大的一处，直说理由：**

1. **扩建会把玩具改造成进度阶梯。**「扩一圈 = N 煤永久消耗」看似健康的沉没端，实际给家园装上了「大小 = 财富」的成长轴——孩子的注意力从「怎么搭」滑向「怎么变大」，表达层重新长出优化压力。这正是商店问题（线性清单，买完即终/扩完即终）换了个皮回来。
2. **约束养表达。** 固定画布是乐高底板逻辑：有限格子里的重排与取舍才是创作；无限画布稀释密度，成品反而更难「像个作品」。
3. **交互成本真实**：16×9 恰好贴合 iPad 横屏，扩建即引入滚动/缩放/平移，对 4 岁是操作负担，对工程是新交互面。
4. 经济上不需要它：永久沉没端有星空即可，煤只是一个数字，余额慢慢变大本身也是记录。

若未来确实需要第二个煤沉没端，候选是「烟花」类一次性庆祝消耗（放完即逝、不留存量、不成阶梯），列遗留待决策第 5 项备考，v1 不做。

### 问 4：观察清单——沉浸搭建 vs 逃避做题

**现有第 3/5 条适用，但第 3 条必须打补丁，另立建造专项。** 核心修正：对装备屏，「大半时间停在养成屏」本身可疑（那屏没有可玩内容，长驻只可能是兑换焦虑）；对家园，**长时间沉浸是玩具的正常使用形态**（等同于地板上拼乐高），时长单独不构成信号。裁判换成组合条件：**周答题量走势 + 退出位置**，具体条目见下文「观察清单增补」。

区分的操作化标准一句话：**健康沉浸看「搭完之后发生什么」（展示、命名、讲故事、重摆），逃避看「搭之前发生了什么」（是不是刚遇到某类新题就退出来了）。** 前者是评审最想要的展示物行为的最强形态——家园比装备更容易触发「爸爸你看」，因为它是孩子造的，不是孩子买的。

新增一条家长侧红线（这是建造层独有的新风险面）：**家园越好玩，家长越容易拿它当筹码**（「先做两关才能搭」）。这句话一出口，就把 M1–M7 在代码里守住的东西在客厅里全丢了——煤价已经完成了数学与家园之间唯一需要的温和耦合，人为加门等于把玩具改造成计件工资。写进观察清单随 M6 交付。

### 问 5：方块目录与可持续

- **8 种起步：够开局（2–4 周的新鲜度），但有一块明确短板——颜色。** 现有 8 种（草/泥土/木板/石头/玻璃/栅栏/花/火把）色域集中在绿棕灰，孩子在网格上「画画」（像素画是这个年龄最自然的搭法）缺原色。**推荐 v1 直接补白/红/蓝羊毛三色，托盘 8 → 11**（纯色 tile，素材成本约等于零，一屏托盘放得下）；若工程要冻结范围，羊毛三件作为上线后第一个补丁，不等新章。
- **内容更新对应规则修订（写进规范）**：一章 = 新装备阶 ×1 + 主题配件 4–6 件 + 星座图样 1–2 个 + **主题方块 2 种（免费入托盘）**。第五章（下界主题）示例：下界岩 + 荧石。**免费**是关键：方块种类若要用矿石解锁，就长出第二条购买阶梯，稀释「1 煤 = 1 方块」的单纯性；新方块的到货本身就是 M5 式事后惊喜（打开家园发现托盘多了两格），且免费发放彻底避开「矿石耦合内容」红线的任何边缘试探。
- **1 煤 = 1 方块：确认，并升格为铁则——所有方块永久统一价，禁止差异定价。** 玻璃比泥土贵的那一刻，「贵的建筑 = 好的建筑」的评价轴就诞生了，玩具边界（问 3）即告失守。统一价的额外收益：家园里的方块数 = 花掉的煤数，1:1 对应是数数的根基概念，说明卡一句话就能讲清（M3）。

### 问 6：信息架构——家园做主视图还是第三标签

**主视图，明确推荐，不做第三标签。**

1. **场景优先符合这个年龄的认知方式**：标签是抽象分类，场景是具体世界——把导航从「装备/工作台/家园三选一」变成「走进史蒂夫的家，衣柜在那儿、工作台在那儿」，等于把 CPA 的 C 层逻辑用在了导航上。MC 语境里工作台本来就是摆在地上的一个方块，场景内点它进工作台抽屉，是零学习成本的原生心智。
2. **主视图让三层奖励第一次同框**：进屏一眼看到穿着装备的史蒂夫、走动的宠物、头顶的星、自己搭的方块——首轮「把四条进度汇进一个容器」的论点在这一屏上成为字面事实。这一屏就是给爸爸看的那个「展示物」。
3. 第三标签会把最有生命力的一层埋在 chrome 后面；4 岁孩子不系统性探索标签。

具体形态（供 spec 落）：进屏即家园场景；**固定图标按钮两个**（衣柜 → 装备抽屉；工作台 → 制作/兑换/点星抽屉）常驻角落做可靠入口，场景内点史蒂夫 = 衣柜同义入口、点工作台方块 = 工作台同义入口（双通道：图标保可靠性，场景保具象性）；建造托盘由「方块托盘」按钮唤出，沿屏底展开，选方块点格子放置；**点星操作仍只在工作台内**（家园天空只做展示，避免误触点掉 10 煤）。首进欢迎语音报出两个抽屉的名字（识字有限，导航靠语音，继承次轮问 0 结论）。

### 问 7：M1–M7 之外的新呈现风险

结算屏「去搭点什么」：**不做，同意并条款化**（见结论摘要第 7 条）。逐面排查后，新增两条纪律与三条小规则：

- **M8（新增，硬条款）：场景角色无需求、无召回。** 史蒂夫和宠物不饿、不困、无心情值、不想要任何东西、不想你——他们只是在。这是家园引入的最大潜在暗渠：一旦角色「住」进场景，迭代者天然手痒加照料机制（喂食/睡觉/心情），而照料机制的留存原理是**内疚与损失厌恶**（电子宠物机制），作用在 4 岁孩子的依恋上，是全产品最不可接受的黑模式。与禁签到、无惩罚同源，一并写死。
- **M9（新增，硬条款）：家园无任何完成度表征。** 永不显示「N/144」、填充百分比、进度条、空地高亮或虚线框。空地是邀请，不是缺失；出现分母的那一刻，「铺满地皮」就成了任务，玩具退化为清单（次轮「连?都不给」的空槽原则在空间维度的对应物）。可以显示的唯一数字：托盘上的煤余额（花费决策需要），以及煤说明卡里的「家园里用了 N 块煤」（无分母、主动查询才见）。
- 小规则三条：① **家园不出现在地图屏**（无缩略图、无一角露出；星空维持现状）——家园若上地图，等于全 App 常驻一块奖励广告牌；② 收回工具用**模式切换**（托盘上的小锤子图标），不用长按（4 岁长按困难）；误触零成本——收回全额退、重放免费，交互自我原谅；③ 放置/收回音效轻软、无 TTS 逐块播报（放一块念一句会把孩子逼疯），仅首几次收回念「煤收回来了」建立可逆心智。

## 可落规范的数值/规则表

### A. 地皮与方块

| 项 | 值 | 备注 |
|---|---|---|
| 地皮 | 16×9 = 144 格，**固定，无扩建** | 贴合 iPad 横屏；144 即建造层煤冻结上限 |

## 观察清单增补条目（建造专项，随 M6 一并交付；原 1–6 条保留）

**先改一处旧条款**：第 3 条「每次会话大半时间停在养成屏」在家园语境下**时长不再单独作为信号**——沉浸搭建 20 分钟等同于地板上拼乐高，是玩具的正常用法。该条改为：「会话大半时间在养成屏**且周答题量连续两周下滑**」，两个条件同时满足才干预。

新增：

7. **连续多次会话只进家园、完全不碰题，且周答题量下滑**——单次纯搭建会话完全正常（那是玩耍日）；连续两周如此才需要和孩子聊聊，聊的第一句是问他最近的题难不难，不是关开关（可能是难度问题借家园表达，同第 5 条逻辑）。
8. **答题中途反复退到家园**：处理方式同第 5 条——先看退出卡在哪类题，难度问题先修内容坡度，别急着怪家园。
9. **想要星星/铁甲但舍不得收回方块，来回纠结**——不是病理信号，是绝佳的数学对话时机：陪他算一次账（10 块煤 = 1 颗星 = 10 个方块；4 块煤 = 1 块铁）。纠结本身说明他在真实地做取舍，这是这套系统想教的东西。
10. **家长红线（对爸爸，不是对孩子）**：永远不要说「先做两关才能搭」。家园不需要被挣得——煤价已经完成了全部耦合。一旦孩子开始讨价还价（「我搭够了才做题」），先检查是不是大人先用了交易措辞。

**健康信号增补**（放心清单）：给建筑起名、讲故事；推倒重搭（重来是玩耍不是浪费，煤会回来）；新方块到货后主动重新布置全家园；把家园上空的星指给你看。这些是本模块最想买到的展示物行为。

## 验收标准（增补，孩子行为层面）

1. 首次进家园，听完欢迎语音后**不看提示自己完成第一次放置和第一次收回**——理解可逆性是本层的关键验收（不懂「收回退煤」的孩子会把放置当成永久花费，产生不必要的谨慎）；
2. 两周内出现**命名/讲故事/主动展示**行为至少一次；
3. 上线两周，周答题量与首答正确率不降（唯一裁判，继承）；
4. 「首次会话闭环」验收更新为：首次会话内完成**任意一次花费行为**（穿上皮革靴或放下第一块方块，二者等价有效）；
5. 星空 6 周判据不触发（或触发后按 D 表动作处理）；
6. 不出现家长侧交易话术引发的讨价还价（观察清单第 10 条）。
