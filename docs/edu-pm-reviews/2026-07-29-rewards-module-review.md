## 结论摘要

**判断：改造后做。方向成立，但当前提案的经济系统（掉落条件 + 配方数值）必须重做，否则会在第 4 座建筑处对两类孩子同时死锁——包括你自己的孩子。**

四句话结论：

1. **方向成立，理由只有两条**，其余（矿石好看、MC 主题）都是包装：① 它是全 App 第一个把主线/无尽/冲刺/星图四条互不相通的进度**汇到一个容器**里的东西；② 它给孩子第一个**可支配的选择**（建什么、何时建、要不要兑换）——自主性是近年 gamification 元分析里唯一稳定见效的维度。凭这两条它不是成就墙换皮，值得做。
2. **当前掉落梯度会死锁，且不只坑弱孩子。** 钻石总供给只有 4 颗（4 章），而示例配方一座就要 3 颗；金挂「破纪录」，而破纪录的间隔近似指数增长，两周后归零；绿宝石只在第四章可得；铁要 3 星。**你的孩子从第 46 关跳级起步，低章根本没有星星，「章节全清」对他永久不可达**——现提案里最顺的反而是「从第 1 关线性走到第 60 关的中间孩子」，那是最不需要优化的那一类。
3. **过度奖赏（overjustification）风险真实存在，且对 4–8 岁比成人更强**（元分析：有形奖励对儿童更不利）。但风险的**大头不在"给不给煤"，在三件呈现层的事**：做题界面出现矿石计数、"还差 N 块"的主动催促、以及爸爸把它当筹码说出口。缓解方案不是砍奖励，是**呈现纪律 + 近端化 + 一个家长可随时关掉的开关**。
4. **合成台应该提前到第一期，但只做削减版（固定 4:1 上行兑换）。** 它一次解决三件事：经济死锁的兜底阀、把奖励变成「数学本身」（近端奖励，实证上是唯一不减损内在动机的奖励形态）、以及自主性抓手。成本 S，是本模块投入产出比最高的一块。

**不同意的地方，明说**：① 「金 = 破纪录」必须换掉；② 「钻石 = 章节全清」必须换掉；③ 「绿宝石 = 每 9 句」的口径（当前点亮数）会**倒退**，违反你自己定的铁律；④ 6 个槽位数量对，但**建造事件只有 6 次太少**，应拆成 14 次。

## 一、过度奖赏效应：证据、风险定位与缓解

### 1.1 证据现状（够用即可，不堆文献）

- **有形奖励确实会减损内在动机，且儿童受损更重。** Deci、Koestner & Ryan（1999）对 128 项实验的元分析：有形奖励整体 d = −0.34；按契约类型拆开，**参与依存**（做就给）d = −0.40、**完成依存**（做完就给）d = −0.36、**表现依存**（做得好才给）d = −0.28。明确写到「有形奖励对儿童比对大学生更不利」。
- **边界条件比效应本身重要。** 同一份元分析：**意外的**（事后才知道有奖）有形奖励**不**减损；言语肯定**提升**内在动机（但对儿童提升幅度小于成人）。Lepper 等（1973）那个经典的学前儿童画画实验，被削弱的是「事先被许诺奖励」组，事后惊喜组与无奖励组无差异。**关键变量是"事前许诺 vs 事后记录"，不是"有没有奖励"。**
- **奖励的"近端性"能翻转结论。** Marinak & Gambrell（2008）：用**书**奖励阅读的孩子，后续阅读动机与**完全无奖励**组持平；用代币奖励的孩子显著更低。**奖励物离目标行为越近，越不减损。**
- **游戏化本身不是毒药，但收益点不在"胜任感"。** 2023–2024 的几份元分析：游戏化对内在动机有小而显著的正效应（g ≈ 0.257），提升的是**自主感与关联感**；对**胜任感需求的满足并不显著优于非游戏化**——徽章/积分/排行榜若被感知为"控制"，则反向减损。
- **一条经常被忽略的对称结论**：奖励减损的前提是「任务本身已有内在兴趣」。对孩子本来不太想做的重复性任务，奖励不减损、常常提升。

### 1.2 风险在这个设计里的分布（按风险从高到低）

| 组件 | 契约类型 | 风险 | 判断 |
|---|---|---|---|
| **煤（完成任意关即得）** | 完成依存，d≈−0.36 | **最高** | 你的孩子对新关卡有真实内在兴趣（"太简单"= 主动要更多），正是最容易被挤出的场景。但**保留**——见下方缓解，风险来自呈现而非条件 |
| **铁（星级）** | 表现依存，d≈−0.28 | 中 | 携带胜任信息，CET 里减损最轻的一类；且与既有星星同源，不新增控制感。真正的风险是诱发"求全对"焦虑 → 用 2 星也给铁化解 |
| **金（练习量）** | 参与依存，名义 d 最高 | **实际最低** | 反直觉但重要：练习模式本来就是重复劳动、内在动机弱，奖励在这里不减损反而提升。**外部激励应该重仓在这里** |
| **钻石 / 绿宝石（里程碑）** | 里程碑式、间隔以周计 | 低 | 不构成"逐题交易"关系 |
| **（机制层）做题屏出现矿石计数/掉落动画** | — | **最高** | 奖励线索在"正在做数学"的那一刻显著性最高时，挤出效应最强，且额外占认知负荷 |
| **（机制层）"还差 3 块就能建灯塔！"的主动弹窗/角标** | — | **最高** | 这是把奖励从"事后记录"变成"事前许诺"，直接踩中 Lepper 的分界线 |
| **（机制层）家长口头当筹码**："你去做两关，能挖到煤" | — | **最高，且不在代码里** | 唯一解是给爸爸一页话术 |

**一句话定位**：这个设计里最危险的不是任何一种矿石，是**奖励在"做题当下"的可见性**和**未来式许诺的措辞**。条件本身可以保留，呈现必须立规矩。

### 1.3 六条缓解措施（全部可直接写进规范）

- **M1 呈现纪律**：矿石**不进答题屏**（无计数、无掉落动画、无音效）。掉落只在**关卡结算屏**出现一次，动画 ≤ 1s、无强音效。地图上港口入口**不带红点/数字角标**。
- **M2 语言纪律**：全部文案用「你挖到了 / 你的港口」，**禁止**「奖励你 / 赢得 / 达成」的交易措辞，**禁止一切未来式许诺**（「再做一关就能……」）。港口屏内静态显示差额（「还差 3 块煤」）是可以的——那是孩子主动进来时的信息，不是推送。
- **M3 近端化（最关键）**：把奖励屏本身做成数学对象——配方用**点阵成组**呈现（20 块煤 = 4 组 5 块，复用计数块/阵列网格的视觉语言），差额用「还差几块」，兑换用「4 块煤换 1 块铁」。这是 Marinak & Gambrell 那条结论在本产品的落法：**让奖励物离数学近到几乎就是数学**。
- **M4 自主性**：允许**乱序建造**（"固定槽位"理解为"位置固定"而非"顺序固定"，材料够就能建）；建造时机完全由孩子选；兑换是可选的、可不用的。自主感是元分析里游戏化真正见效的维度。
- **M5 首次亮相设计为"事后惊喜"**：因为掉落是**从既有进度派生的**（见 §3.1），孩子第一次打开港口时，**矿石已经根据他过去的全部进度堆在那里了**。这在实证上是最安全的引入方式：意外的、回溯性的、"你过去做过的事的记录"，而非"以后做事的许诺"。**不要**在上线前预告「以后做题能挖矿」。
- **M6 可逆退出（硬性交付）**：家长设置里加「港口」开关（默认开），并配一页**观察清单**。我们无法预测这个孩子的反应，唯一诚实的做法是留一个开关和一张观察表：

  > 出现下列任一，先关掉港口两周：① 主动问"这关能挖到几块矿"再决定玩不玩；② 催着跳过计数块/朗读，答题明显变快变糙（首答正确率下降）；③ 只肯玩已经会的关卡、拒绝新内容；④ 建完一座后立刻问"还有没有"，而不是回去玩关卡。
  > 反过来，健康信号：他把港口当**展示物**（主动指给你看、给建筑起名字），而不是当**兑换机**。

## 二、掉落梯度：现提案会死锁，必须重做

### 2.1 现提案的四个断点（逐条量化）

| 条件 | 终身总供给 | 问题 |
|---|---|---|
| 煤 = 完成任意关 | **60**（每关一次） | 唯一没问题的一条 |
| 铁 = 3 星通关 | ≤ 60 | 弱孩子近乎归零；且「必须全对」与无惩罚铁律有张力 |
| 金 = 无尽/限时破纪录 | **收敛到 0** | 破纪录间隔近似指数增长：前两周天天破，第 3 周起几乎不再发生。这是一条**消退曲线**——恰恰在孩子需要靠练习巩固的阶段，练习的奖励归零 |
| 钻石 = 章节全清 | **4** | 示例配方「观星台 = 10 金 + 3 钻」一座就吃掉 3/4 的终身供给。**两座建筑各要 3 颗即数学上不可能** |
| 绿宝石 = 每点亮 9 句 | **4** | 且第 46 关才解锁星图；更严重的是——`litBest` 才是单调高水位，**当前点亮数会因答错回落**（`onWrong` 令 `s−1`）。若按当前点亮数算，孩子会**眼看着绿宝石消失**，直接违反「无失败态、无倒退」铁律 |

### 2.2 最致命的一点：卡的不只是弱孩子，还有你的孩子

「章节全清（该章 15 关全部得星）」对一个从第 46 关跳级起步的孩子**永久不可达**——他没有第一到三章的星星。要拿钻石，他必须回头去刷 45 关自己觉得"太简单"的内容。

这就制造了本模块最坏的一种失败：**为了矿石去做低于 ZPD 的数学**。它同时踩中两条红线——违反最近发展区（花时间在踮脚不用够的内容上），以及正是"外在动机挤出内在动机"的教科书机制（数学从目的变成手段）。

**因此定一条硬约束（写进规范）**：

> **任何掉落条件都不得使"回头刷低于当前水平的内容"成为最优路径。**具体化为三条实现规则：① 所有条件是**单调累计阈值**，不是事件；② 所有条件**路径无关**（不要求"同一章"「连续」「全清」）；③ 重玩同一关只有在**星级提升**时才产出增量。

### 2.3 修复后的掉落表（推荐落地版）

五种矿石 = 五种不同的行为，每种至少两条来源路径，全部单调不减、全部是 `Progress` 的纯函数：

| 矿石 | 公式 | 语义（给孩子的一句话） | 备注 |
|---|---|---|---|
| **煤** | `#{关 star≥1}` + `floor(P/8)` | 「走过的每一段路」 | 主线部分上限 60；练习部分可再生 → 常见矿，符合 MC 心智 |
| **铁** | `Σ(star−1)`：2 星给 1、3 星给 2 | 「做得仔细」 | 上限 120。**2 星也有收获**，避免"必须全对"的焦虑；重玩只在星级提升时产出增量（= 定向重练你没掌握的关，是好行为） |
| **金** | `floor(P/25)` | 「练得多」 | 无上限，唯一真正可再生的中阶矿 → 外部激励重仓在教育价值最高、内在动机最弱的分布式重复上 |
| **钻石** | `floor(N★/10)` + `floor(P/200)` | 「走了很远」 | 路径无关的里程碑；跳级孩子靠练习也能拿 |
| **绿宝石** | `floor(litBest/3)` + `floor(bestStreak/10)` | 「记住了 / 越来越顺」 | **必须用 `litBest` 高水位**，不用当前点亮数；`bestStreak` 同样是高水位，给未进第四章的孩子一条慢速通路 |

其中 `N★` = 得星关数，`P` = 三个练习模式的**累计首答即对题数**。

**为什么 P 必须是"首答即对"而不是"答对"**：无尽模式答错只排除选项、原地重试，最终**每题都会变成"答对"**（`totalAnswered += correctCount`）。若按此计数，孩子可以靠**乱点三个选项**刷矿。改成首答即对即可根除，而且它是更诚实的信号（"你真的会的题"）。这不违反无惩罚——**没有奖励 ≠ 惩罚**，前提是界面**绝不显示**"这题没挖到煤"。全程静默。

**farm-proof 是这套公式的结构性优点**：煤/铁由 stars 派生（每关封顶）、钻石/绿宝石是高水位、金/煤的练习部分由首答即对驱动——**没有任何一条可以通过重复低水平劳动刷出来**。

**顺带一个额外好处**：掉落按**关**计而不按**题**计，所以家长把 `questionCount` 从 5 调到 3 不会加速经济，避免了「家长旋钮意外破坏节奏」这类事故（首评 P0-1 同类问题的预防）。

## 三、配方数值：具体数字与推导

### 3.1 先定架构：掉落全部**派生**，只存"花掉的"

```
余额 = 派生所得(Progress)  −  已消耗(built 记录)  ±  兑换记录
```

`Progress` 新增一个切片即可（`storage.ts` 的 merge-over-defaults 天然向后兼容，星图切片已是先例）：

```ts
rewards: {
  practiceFirstTry: number;             // 三模式累计首答即对（唯一新埋点）
  built: Record<string, 0 | 1 | 2 | 3>; // 建筑 id → 已完成阶段数
  traded: { coal: number; iron: number; gold: number; diamond: number; emerald: number }; // 兑换净额
}
```

这条架构选择不是洁癖，它买到三件事：① **不可能出现重复发放/丢矿的 bug**（余额随时可从进度重算，自愈）；② **迁移即库存**——首次上线时按既有进度直接算出一批矿石（正是 §1.3 的 M5 惊喜引入）；③ 它**反过来强制了健康的经济**——事件式条件（"破纪录次数"）无法派生，必须存计数器，而累计阈值条件天然可派生。**架构和教育学在这里指向同一个答案。**

迁移建议：`practiceFirstTry` 初始化为现有 `endless.totalAnswered`（宽容折算，给老用户一份起步库存）。

### 3.2 节奏目标（先定目标，再倒推数值）

| 里程碑 | 目标时点（"常规使用" = 每周 4 次 × 每次 4 关 + 1 轮练习） | 依据 |
|---|---|---|
| 第 1 座 | **第一次坐下的 10 分钟内** | 循环必须在首次会话内闭合一次，否则规则学不会 |
| 第 2–3 座 | 第 3 天 / 第 10 天 | 高频验证期 |
| 第 4–5 座 | 第 2–3 周 / 第 4–6 周 | 间隔按约 2 倍几何递增 |
| 第 6 座 | **第 8–10 周** | 与内容寿命对齐：常规使用约 4 周走完 60 关，港口应略微**长于**主线，让孩子在通关后仍有回来练的理由 |
| 任意两次"可见进展"的最大空窗 | **≤ 2 周** | 4 岁到 8 岁都撑不住 4 周零反馈 → 由 §3.4 的三阶段建造保证 |

**过快的判据**：第 6 座在 **3 周内**建成 → 数值偏低。**过慢的判据**：第 1 座超过 **15 分钟**未达成，或任意空窗 **> 3 周** → 数值偏高。这两条直接作为调参门槛。

### 3.3 建议配方（可直接落规范）

| # | 建筑 | 总配方 | 目标时点 |
|---|---|---|---|
| 1 | 码头 | 4 煤 | 第 1 次坐下 |
| 2 | 灯塔 | 10 煤 + 4 铁 | 第 2–4 天 |
| 3 | 仓库 | 16 煤 + 10 铁 + 2 金 | 第 1–2 周 |
| 4 | 船坞 | 20 煤 + 16 铁 + 5 金 + 1 钻 | 第 2–3 周 |
| 5 | 观星台 | 24 煤 + 20 铁 + 10 金 + 2 钻 + 1 绿 | 第 4–6 周 |
| 6 | 宝库 | 30 煤 + 20 铁 + 15 金 + 3 钻 + 3 绿 | 第 8–10 周 |
| — | **总需求** | **煤 104 / 铁 70 / 金 32 / 钻 6 / 绿 4** | — |

**推导（常规使用的周收入）**：每周 16 关（≈16 煤、≈16 铁）+ 4 轮练习（≈100 首答即对 → 12 煤 + 4 金）→ **约 28 煤 / 16 铁 / 4 金 / 1.6 钻 / 0.5–1 绿**。走完主线（约第 4 周）后主线侧收入归零，只剩练习侧 ≈ 12 煤 + 4 金 + 0.5 钻 / 周，铁靠回刷星级与兑换。

按此逐座模拟（扣除已花费）：码头 Day 0 → 灯塔 Day 3 → 仓库 Day 10 → 船坞 Day 16 → 观星台 Day 30 → 宝库 Day 60。**命中目标节奏**，且后期瓶颈自动落在**金与绿宝石**上——也就是"去练习、去记口诀"，这正是我们希望外部激励压住的行为。

**三类孩子的健壮性检查**：

- **弱孩子**（每周 3 次 × 2 关 + 1 轮短练习，平均 1.3 星）：周收入 ≈ 10 煤 / 2 铁 / 1.4 金。铁是瓶颈 → 仓库要等到第 7 周；**但他煤是过剩的**（累计 60+），用 4 煤→1 铁 兑换可提前到第 4–5 周。**没有死路，只是慢**——而他的内容进度本来也慢，模块寿命与内容寿命同步。这就是 Q2 的正面回答：**兑换阀把"我拿不到 3 星"翻译成"我多练几轮就能换"，努力永远可兑换为进展。**
- **跳级孩子（你的）**：主线只有 15 关 → 煤 15、钻 1，但练习/星图产出高。煤靠练习侧补（`P/8`），钻靠 `P/200` 补，绿宝石因星图而富余。总需求 104 煤在第 9 周可覆盖并有余量。**不需要回刷任何低于 ZPD 的关卡。**
- **狂热孩子**：会被钻石与绿宝石的产出速率自然限流，最快约 5–6 周通关港口，不会"几天就建完"。

### 3.4 三阶段建造（解决"第 5→6 座之间 4 周空窗"）

第 3–6 座各拆 3 个建造阶段（地基 / 主体 / 完工），每阶段约 1/3 材料，**每阶段都由孩子按"继续建造"触发**——不自动推进。港口上对应三张贴图。

| 建筑 | 阶段一 | 阶段二 | 阶段三 |
|---|---|---|---|
| 仓库 | 6 煤 + 2 铁 | 6 煤 + 4 铁 | 4 煤 + 4 铁 + 2 金 |
| 船坞 | 8 煤 + 4 铁 | 8 煤 + 6 铁 + 2 金 | 4 煤 + 6 铁 + 3 金 + 1 钻 |
| 观星台 | 10 煤 + 6 铁 + 2 金 | 8 煤 + 8 铁 + 4 金 + 1 钻 | 6 煤 + 6 铁 + 4 金 + 1 钻 + 1 绿 |
| 宝库 | 12 煤 + 6 铁 + 4 金 | 10 煤 + 8 铁 + 5 金 + 1 钻 + 1 绿 | 8 煤 + 6 铁 + 6 金 + 2 钻 + 2 绿 |

前两座不分阶段（首个循环必须快）。**建造事件因此从 6 次变成 14 次**，最长空窗从 30 天压到约 12 天，经济总量一点没变。

### 3.5 合成台 v1：固定 4:1 上行兑换

```
4 煤 → 1 铁    4 铁 → 1 金    4 金 → 1 钻    4 钻 → 1 绿宝石
```

- **为什么是 4 而不是 3**：3:1 时 27 煤 = 1 钻，煤的终身产出就能刷出 2 颗钻，稀有度崩塌；4:1 时 1 绿宝石 = 4 钻 = 16 金 = 64 铁 = **256 煤**，兑换永远不是划算路径，只是**保险**。（唯一需要保留的可调旋钮：若实测第 3 座之后普遍卡顿，再降到 3:1。）
- **只向上、不向下**：避免出现"拆解"这一层额外规则；也避免孩子把稀有矿换成一堆煤后后悔（无倒退）。
- **它就是数学**：4 换 1 是 ÷4 与 ×4 的具身，视觉上 4 组 1 块 → 1 块，是标准的 P 层表征。这条让整个奖励系统从"代币"往"书"的一侧移动（近端奖励）。

## 四、「不做每日登录奖励」——完全同意，且应升级为铁律

**这是本提案里最正确的一个决定，我不提供替代方案，因为不该有。** 四条理由：

1. **连续签到是纯粹的损失厌恶机制**：断签的心理成本大于签到的快感，其动力来源是"怕失去"，与产品的无惩罚铁律根本冲突（断签的连续天数归零就是一个惩罚展示，不管你把它画得多可爱）。
2. **5 岁孩子不控制自己的日程**，是爸爸决定今天开不开 iPad。因此签到实际上是**因为一个他无法控制的决定而惩罚他**——自我决定论里最典型的自主性剥夺，也正是元分析中游戏化"翻车"的那一类设计。
3. **它把家长变成 App 的催收员**，制造屏幕时间压力，损害的是这个产品最脆弱也最重要的资产：数学在家里的情绪底色。
4. **日期依赖的奖励是"控制性奖励"的原型**，减损效应在儿童身上更强。

**推论（一并写进规范）**：不仅不做连续登录，也**不做"每日掉落上限"**——日上限同样把节奏绑定到日期上。防刷靠 §2.3 的 farm-proof 公式结构，不靠日上限。

**如果确实想促成跨天的分布式重复，唯一允许的形式**：内容侧、隐式、无计数——九九星图已有的 `cd` 间隔机制（单位是"会话"而非"天"）就是正解；最多允许星图入口出现一句柔和的「有几句口诀想你了」，**不带天数、不带倒计时、不带连续记录**。

## 五、6 个建造槽位：数量对，节奏不对（已在 §3.4 修好）

- **6 个槽位数量合适**：少于 4 撑不满 8 周；多于 8 每座的分量被稀释，且美术成本线性上涨（美术是本模块真正的成本瓶颈，不是逻辑）。
- **但"6 次建造事件"太少**——8–10 周里只有 6 个高光时刻，后半程会出现 4 周零反馈。§3.4 拆成 **14 次**即可，经济总量不变。
- **固定槽位 + 建造按钮、不做自由拖放：同意，理由比你说的还多一条**——它与九九星图的"格子点亮"交互同构，孩子**零学习成本**；而拖放除了精度问题，还会引入"摆得好不好看"的自我评判，那是这个年龄不需要的负担。
- **建议乱序建造**（材料够就能建任意一座）：这是本模块最廉价的自主性来源，且不影响节奏（配方本身已排序了难度）。
- **揭示策略：渐次显形**，不要一次亮出 6 个空槽。已建成的 + 下一座（半透明剪影 + 配方）可见，再往后是「？」。一次一个清晰的近目标；6 个空位对 5 岁是"我有 5 样东西没有"的缺失感框架。
- **建造动画**：1.5–2s 升起，粗描边风格，一次性；不重复播放、不做"炫耀回放"。

## 六、该加与该砍

### 该加

1. **合成台提前到第一期（削减版，§3.5）** — 强烈建议。它是死锁兜底阀 + 近端奖励 + 自主性，三合一，成本 S。
   你判断"完整合成台教育价值最高"是对的，但那份价值主要来自**"配方即乘法"的具身**（3 组 × 4 块），那需要第四章的乘法语境；而 **4:1 兑换在任何章节都成立**，且是除法直觉的早期铺垫。拆成两段刚好：v1 兑换阀，v2 多材料合成表。
2. **矿石"来源可见"**：点任一矿石 → 弹小卡说明它从哪来（「煤：每走完一关，挖到 1 块」）。这是把奖励从"神秘掉落"变成"我做过什么的记录"的具体落法，即 informational 而非 controlling。
3. **配方与差额用数学表征**（M3）：点阵成组、"还差几块"。让港口屏本身有教育内容。
4. **家长开关 + 观察清单**（M6）：硬性交付，不是可选项。
5. **重置进度的二次确认必须提到"港口的建筑会被拆掉"**：矿石派生自进度，重置必然连港口一起清零。一个爸爸为了让弟弟妹妹玩而点的重置，会摧毁孩子几周的情感投入——这是本模块引入的**新的**破坏性后果，文案必须明说。
6. **与家长会话小结同批交付**：本模块是本产品第一个**已知带副作用**的机制，而首评 P0-2（本地家长小结）至今未做。闭着眼上一个有已知风险的激励机制，是这次最不该犯的错。小结里加一行「本周他的首答正确率 / 是否出现答题变快变糙」即可。

### 该砍 / 该改

1. **砍**：金 = 破纪录 → 改为累计练习量阈值（消退曲线 → 线性供给）。
2. **砍**：钻石 = 章节全清 → 改 `floor(N★/10) + floor(P/200)`（路径无关，跳级孩子可达）。
3. **砍**：绿宝石 = 每 9 句（当前点亮数）→ 改 `floor(litBest/3) + floor(bestStreak/10)`（单调高水位，杜绝倒退）。
4. **砍**：答题屏内的一切矿石元素（计数、掉落动画、音效）。
5. **砍**：任何主动催促——"还差 N 块"的弹窗、地图港口入口的数字/红点角标、结算屏的"再玩一关就能……"。
6. **改**：铁 = 3 星 → `Σ(star−1)`（2 星给 1、3 星给 2），消除弱孩子的铁归零和"必须全对"的焦虑。
7. **永久禁止（新铁律条款）**：**矿石不得与数学内容耦合**——不得解锁关卡、不得影响难度、不得兑换"跳过一题"。一旦矿石能买到内容，它立刻从装饰品变成控制机制，本文所有缓解措施同时失效。

### 明确不做

- 每日/连续登录奖励、连续天数展示、每日掉落上限（§四）。
- 矿石排行榜、与他人比较的任何形态。
- 稀有度随机掉落（抽卡式）：随机强化会显著增强"为奖励而做"的行为黏着；这个年龄段不需要。**全部掉落必须确定、可解释、可预期**。
- 限时活动 / 季节性矿石：同样制造日期依赖。

### 验收标准（孩子行为层面可观察）

1. **首次打开港口**（已带既往进度折算的一批矿石）时，他能**不看提示自己完成第一次建造**——固定槽位交互与星图同构的验证。
2. 上线后两周内，**关卡首答正确率不下降**、**平均每题用时不缩短 > 15%**——没有为矿石而糙做的迹象。
3. 他把港口当**展示物**：主动指给爸爸看、给建筑起名、点矿石听来源，而不是每次做题前先问"这关能挖几块"。
4. **练习模式（无尽/冲刺/星图）的使用频次上升**——这是本模块唯一真正想买的结果（分布式重复）。
5. **不出现回刷低于当前水平关卡的行为**——公式的路径无关性生效。
6. 第 1 座在首次会话内建成；第 6 座在 8–10 周落成（若显著偏离，按 §3.2 的两条判据调参）。

### 实现成本量级

| 项 | 量级 |
|---|---|
| 派生掉落公式 + 单测（纯函数，约 50 行） | S |
| `Progress.rewards` 切片 + storage 合并一行 + 迁移折算 | S |
| 合成台 v1（一屏 + 4 个兑换按钮） | S |
| 港口屏（新 screen，复用现有 token）+ 建造交互 + 三阶段状态机 | M |
| **美术：6 建筑 × 3 阶段 + 5 矿石图标 + 港口底图** | **M–L（真正的关键路径）** |

逻辑侧完全在数据驱动架构的舒适区；**风险在美术产能与风格一致性**，建议先出 1 座建筑的三阶段试样，确认 agnes-ai 能稳定复现动森风粗描边后再批量。

## 遗留待决策项

1. **终局处置**：第 6 座建成后矿石流向哪里？若无处可去，掉落在孩子投入最深的时刻变成噪音，并**回溯性地贬值**先前所有奖励。最小方案：港口进入"母港"完成态，此后矿石自动转为**环境装饰**（旗子、灯、小动物）缓慢生长，无需选择。需要美术成本评估。**这项必须在 v1 上线前定，不能拖到二期。**
2. **美术产能**：18 张建筑状态图是否可行？若不可行，退路是 6 建筑 × 2 阶段（建造事件降到 10 次，空窗略增），或用统一的"脚手架"叠加层表示中间态（成本大幅下降，风格损失可接受）。
3. **家长开关默认值**：我建议默认开（否则等于没做）；若你想先观察一周再引入，可默认关、由爸爸手动开启——这也顺带实现了"事后惊喜"的引入。
4. **兑换比 4:1 vs 3:1**：推荐 4:1，保留为唯一调参旋钮。
5. **重置进度是否应保留港口**：当前架构下不可能（派生自进度）。是否值得为此加一个"只重置关卡进度"的选项，需工程评估；短期用文案告知兜住。
6. **`practiceFirstTry` 的迁移起点**：建议按现有 `endless.totalAnswered` 折算（给老用户起步库存）；若你希望首次港口更"空"一些以保留成长感，可折半计入。
7. **是否与家长会话小结同批上线**：我的强烈建议是「是」。若要分批，至少先做小结再做港口，不要反过来。
