## 0. 设计总则（本章特有约定）

1. **除法域 = 九九口诀反用**：一切除法题的被除数 `c = a×b`，商 `a ∈ [2,9]`、除数 `b ∈ [2,9]`（÷1 平凡、÷0 违反「不出 0」，均永不出现；无余数除法，「有余数」列为后续扩展钩子，本版不做）。
2. **题面 key**：`operands + ops + kind(missingIndex)`——`12÷3` 与 `12÷4` 是两个题面；混合档各子池 kind 互异，合计数无跨池重复，EXACT 断言可用精确和。
3. **一次一个新概念**：段 1 引入「÷ 与分一分」；段 2 只扩除数域；段 3 引入缺数位置（先缺中、后缺首，沿第二章 `a+?=c`→`?+b=c` 先例）；段 4 只做并置；段 5 引入两步。相邻章重叠：档 61/62 含 ×2/×5 复习子池，档 70–74 直接复用第四章池。
4. **hardMode 语义不变**（仅加法计算子池转缺数）：本章乘除题、连算题一律不受影响。
5. 答案排序、整关去重、混合档整关强制配比、滚动去重等全局规则原样继承。

## 2. 封闭约束域与计数（工程可枚举）

- **div(D)**：`{(q,b) : q∈[2,9], b∈D}`，题面 `q·b ÷ b`。计数 = `|D| × 8`。档 63/64/65/66 = 16/16/32/64。
- **档 61/62 乘法复习子池**：`{(a,b)∈[2,9]² : a=t 或 b=t}`（t=2 或 5）= `8+8−1 = 15`。
- **missing-div-b（c÷?=a）**：div([2,9]) 剔除 `q=b` → `64−8 = 56`。
- **missing-div-a（?÷b=a）**：64（不剔除：`?÷6=6` 答案 36 未泄露）。
- **乘法缺数剔平方**（档 71 子池）：missMulB 56 + missMulA 56 = 112。
- **chainDiv**：`(q,b)` 64 组；`÷+`：c∈[1, 100−q] → Σ_{q=2..9}(100−q)×8 = 756×8 = **6048**；`÷−`：c∈[1, q−1] → Σ(q−1)×8 = 36×8 = **288**。
- 混合档 = 子池精确和（kind 互异无重复题面）：69=120、70=128、71=232、72=360、73=6336、74=12672、75=13032。

## 4. 干扰项规则（除法错误模型）

按优先级，越界/撞正确答案/重复即丢弃回落：

1. **商邻位**（div 计算题首选）：`q±1`——口诀串行在商侧的镜像（如 56÷7 给 7 或 9）。
2. **减法混淆**（div 计算题，50% 概率替换一枚商邻位）：`c−b`——引入期真实错误「把 ÷ 看成 −」（12÷2 给 10）。
3. **同积异对**（missing-div-b 首选）：c 的另一组表内分解的除数 `d`（`d|c`，`c/d∈[2,9]`，`d≠答案`，允许 d=可见商）——「拿错口诀家族」（12÷?=4 给 2 或 6）；无异对时回落除数邻位 `b±1`。
4. **口诀邻位积**（missing-div-a 首选，继承第四章）：`(a±1)×b`、`a×(b±1)`（?÷9=9 给 72 或 90）。
5. **半途干扰**（两步题 73/74 首选，新增）：第一步中间结果 `s1`——「只做了一步」（12÷3+5 给 4）。
6. **兜底**：距离干扰 d∈{1,2}，不足逐步扩大。

边界用例（实现后逐条成测试）：4÷2=2 → 商邻位 {1,3}（1 合法）✓；18÷2=9 → 减法混淆 16 ✓；16÷?=8 → 同积异对 {4}（d=2 撞答案剔除）+ b±1 补足 ✓；?÷9=9 → 邻位积 {72,90} 均 ≤100 保留 ✓；12÷3+5 → 半途 4 ✓；商邻位与减法混淆同值时去重回落 ✓。

## 5. 教具方案（C/P 层）

**核心裁决：除法不做常显交互教具，C/P 支撑走「分组揭示卡」（星图揭示先例的主线化）。** 理由：任何把 c 个块按 b 组常显排列的图都等于把商画在屏幕上（数一组即得答案）——「数格子泄底」。揭示只在答错后出现：它是教学时刻，不是惩罚（星图先例；无惩罚原则不受影响）。

- **触发与流程**：除法类题（div / missing-div-*）**首次**答错 → 既有 0.9s 重试反馈清除后展示揭示卡：口诀大字（三四十二）+ 完整等式（12 ÷ 3 = 4）+ 分组图（c 个方块圈成 b 组、每组 a 个，静态描边圈组）+ 语音（§6）→ 点一下继续 → 回题面原地重试（选项排除已生效）。每题至多一次，二次答错走普通重试反馈。
- **段 1 语义分层**：档 61–63 揭示卡念「分一分」句（等分语义先行）；档 64 起念「想口诀」句（检索策略）。
- **平方特判**（参照星图裁决）：`c÷?=a` 不出平方组合（域内剔除，§2）；`?÷b=a` 与计算题不受影响。
- 两步题无教具（继承第四章）；档 61/62 的乘法复习子池维持第四章规则（纯乘法出阵列网格）；档 70/72/75 中的乘法计算题面同。
- 设计权衡记录：段 4「并置」不做同口诀家族的相邻成对出题——整关按答案升序排序的既有规则使相邻成对不可实现，互逆联结由混合在场 + 揭示卡「想口诀」语言承担。
